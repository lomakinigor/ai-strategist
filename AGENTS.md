# AI-Стратег: локальные инструкции

## Бренд

- Для любых изменений публичного UI сначала читать [`docs/brand/DESIGN.md`](docs/brand/DESIGN.md).
- Оригинальный source of truth: [`docs/brand/ai-brand-book-pomelli.pdf`](docs/brand/ai-brand-book-pomelli.pdf).
- Не вводить новые цвета, шрифты или визуальный tone of voice без явного решения пользователя и обновления `DESIGN.md`.
- Допустимы прозрачность и композиции из canonical цветов, если сохраняется доступный контраст.

Остальные правила проекта находятся в [`CLAUDE.md`](CLAUDE.md).

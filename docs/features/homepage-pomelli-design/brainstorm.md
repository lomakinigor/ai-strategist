# Brainstorm: Pomelli-дизайн главной

## 1. Пользовательская проблема

Текущая главная функциональна, но визуально не передаёт технологичность продукта с той же силой, что предложенный Pomelli-макет.

## 2. Current behavior

- Простая статичная навигация без якорей и CTA.
- Светлый центрированный hero без визуального образа продукта.
- Большинство секций используют одинаковые светлые карточки и близкую композицию.

## 3. Desired behavior

- Фиксированный glass-header с якорями и CTA.
- Тёмный image-led hero с контрастным левым контентом.
- Строгая editorial/corporate-система: navy, black, white, off-white, квадратные карточки, тонкие границы.
- Чередование светлых и тёмных секций при сохранении текущих текстов, ссылок и аналитики.

## 4. Ограничения

- Не менять тарифы, обещания, JSON-LD, маршруты и Yandex Metrica goals.
- Не использовать случайный портрет из Pomelli; сохранить реальные фото основателей.
- Новый стиль должен быть scoped к главной и не ломать `/intake`, `/demo`, отчёты и юридические страницы.
- Mobile-first, focus-visible и `prefers-reduced-motion` обязательны.

## 5. Альтернативы

1. Переписать landing с нуля — отклонено: высокий риск потерять SEO-контент и рабочие CTA.
2. Глобально изменить `lp-*` — отклонено: эти классы используются на других маршрутах.
3. Scoped CSS module + точечные JSX-классы — выбрано: минимальный blast radius.

## 6. Риски

- Hero-изображение может ухудшить LCP: локальный asset, responsive background и без JS.
- Fixed header может перекрывать якоря: `scroll-margin-top` и mobile layout.
- Длинные CTA могут не помещаться: responsive stacking.

# Mobile layout главной — brainstorming

## Пользовательская проблема

На экранах 320–430 px шапка, hero-заголовок и тарифные карточки выходят за правую границу. Парные CTA визуально различаются по размеру.

## Current behavior

- Header CTA обрезается и не показывает «Посмотреть пример отчёта» целиком.
- Минимальный размер hero H1 слишком велик для узкого viewport.
- Grid items тарифов могут сохранять min-content ширину и выглядеть смещёнными вправо.
- CTA внутри тарифов и финального блока не имеют общего mobile-контракта высоты и ширины.

## Desired behavior

На 320–768 px нет горизонтального переполнения, все тексты видны, карточки центрированы, соседние CTA равны по ширине и минимальной высоте.

## Ограничения

- Не менять desktop-композицию, тексты, маршруты и аналитику.
- Использовать только Inter и canonical palette из `docs/brand/DESIGN.md`.
- Сохранить доступный focus и `prefers-reduced-motion`.

## Альтернативы

1. Сократить тексты CTA — отклонено: пользователь просит показывать их целиком.
2. Перестроить header в hamburger — лишний scope.
3. Добавить scoped mobile CSS и минимальные class hooks — выбранный хирургический вариант.

## Риски

- Длинный русский текст на 320 px потребует переноса на две строки.
- Высота CTA должна быть минимальной, а не фиксированной, чтобы текст не обрезался.

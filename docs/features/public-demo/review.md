# Review: публичный демо-отчёт

## Результат

Публичный маршрут `/demo` показывает четыре последовательных состояния: ввод → ход исследования → интерактивная часть → полный отчёт. Контент обезличен, дизайн интерактивной части основан только на `innodor-report.html`.

## Acceptance criteria

- [x] Компания представлена как ООО «Юридическая компания»; PII и исходные названия не попадают в snapshot.
- [x] Доказательства: 20+ лет практики, 1+ млрд ₽ взыскано, 5–10 новых клиентов в месяц.
- [x] Технический срез не смешивает замеры: 24 июня 2026, Performance 42/100, LCP 27,3 сек, FCP 6,1 сек.
- [x] Доступны light/dark theme, режим «Только действия», прогресс чтения и печать/PDF.
- [x] Mobile layout переводит верхние действия в сетку и не требует горизонтального размещения четырёх кнопок.
- [x] Production build формирует статический маршрут `/demo`.

## Framing audit

- ✅ Raw-данные первыми: технический замер расположен до AI-резюме.
- ✅ AI маркирован: используется явная метка `AI-резюме`.
- ✅ AI-summary не по умолчанию: блок свёрнут в `<details>`.
- ✅ Нейтральная подача: факты, гипотезы и недостаточные данные имеют разные статусы.
- ✅ Trust-signal: в интерактивной и полной версиях объяснён framing-aware порядок подачи.

## Verification

- `npm test -- snapshot.test.ts innodor-design.test.ts` — 7 тестов проходят.
- `npx tsc --noEmit` — проходит.
- `npm run build` — проходит, `/demo` prerendered as static content.
- Browser smoke прошёл по основному сценарию, theme и режиму «Только действия». Финальный повторный localhost-preview после mobile CSS-фикса заблокирован URL-политикой браузера; фиксация покрыта CSS contract test и production build.

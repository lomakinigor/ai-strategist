# Brainstorm: интеграция бренд-бука

## Understanding

Нужно сохранить официальный бренд-бук Pomelli внутри проекта, превратить его в удобный для разработки источник правил и проверить соответствие стартовой страницы.

## Assumptions

- Бренд-бук является source of truth для всех будущих публичных экранов.
- Существующая структура и контент главной сохраняются.
- Допустимы оттенки через opacity, но новые акцентные hex-цвета вне палитры не добавляются.
- Название шрифта `__inter_fcbcbf` в PDF — техническое имя встроенного Inter; продукт продолжает использовать Inter.

## Open questions

- Нужны ли в будущем отдельные правила для иллюстраций и motion — в текущем бренд-буке они не описаны.

## Варианты

1. Только положить PDF в репозиторий — недостаточно: правила трудно находить и применять автоматически.
2. Переписать всю главную под PDF — избыточно: текущий дизайн уже соответствует композиции и tone of voice.
3. PDF + `DESIGN.md` + точечная коррекция палитры — выбранный вариант.

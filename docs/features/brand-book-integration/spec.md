# Spec: интеграция бренд-бука

## Цель

Сделать бренд-бук постоянным source of truth для интерфейсов AI-Стратега и устранить визуальные расхождения на стартовой странице.

## Требования

1. Исходный PDF хранится в `docs/brand/ai-brand-book-pomelli.pdf`.
2. `docs/brand/DESIGN.md` фиксирует палитру, типографику, голос, ценности и правила применения.
3. Корневой `AGENTS.md` направляет будущую UI-разработку к `DESIGN.md` и PDF.
4. Главная не использует тёплый жёлтый акцент и дополнительные голубые hex-цвета вне утверждённой палитры.
5. Существующие CTA, маршруты, структура секций и responsive-поведение сохраняются.

## Проверка

- Unit contract test проверяет наличие дизайн-гайда и отсутствие запрещённых цветов/класса на главной.
- Существующий Pomelli design test остаётся зелёным.
- TypeScript/build проходят.
- Главная визуально проверена в desktop и mobile viewport.

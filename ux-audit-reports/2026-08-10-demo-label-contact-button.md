## Проверка изменения

- Название «Обезличенный рабочий отчёт» отображается в sentence case без принудительного uppercase.
- Декоративный вопросительный знак удалён из кнопки связи.
- Текст «Написать админу» виден и на desktop, и на mobile; кнопка не превращается в пустой элемент.
- `aria-label`, действие кнопки, модальное окно и focus behavior сохранены.
- Цвета и типографика остаются в рамках brand system.
- Regression-тест защищает оба требования.

## Остаточный риск

Визуальная проверка localhost ограничена browser security policy. Изменение проверено по JSX/CSS-контракту, responsive classes, TypeScript и production build; после публикации проверяются production CSS и JS bundle.
